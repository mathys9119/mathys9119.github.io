Stage en 1ere année de BTS : Suivi des flux CFT sur costream

Je réalise les premiers programmes pour créer une application de suivi des flux, qui sont envoyés au format CFT (Cross File Transfer) via l'application Costream.
Les programmes sont au format Python. Ils accédent à une API, et des fichiers de paramètres au format json (idf, environnement, ...) et texte (clé de connexion).
Les programmes ont plusieurs fonctionnalités. Le première programme permet de connaitre si les flux sont actifs. Le second programme permet d'afficher les données demandées par l'utilisateur. Il envoie également un mail à l'utilisateur pour lui indiquer les informations dont il a besoin.

Projet en 1ere année de BTS : Projet Java

Le projet Java consiste à créer une application de gestion de bibliothèque.
L'application permet de gérer les livres et les auteurs.
L'application est développée en Java avec 2 différents codes.
L'un initalise l'objet livre.
L'autre alimente l'objet livre et affiche les informations concernant chacun des livres.

Projet en 1ere année de BTS : Projet Vlan

Le projet Vlan consiste à créer un réseau informatique avec un VLAN (Virtual Local Area Network).
Le projet est réalisé avec Packet Tracer, un logiciel de simulation de réseau.
Le projet a pour but de m'apprendre à configurer un réseau informatique avec un VLAN.

Projet en 1ere année de BTS : Projet Utilisateur et droits

Le projet Utilisateur et droits consiste à créer et configurer les droits d'accès des utilisateurs.
Le projet est réalisé sur debian, un système d'exploitation Linux.
Le projet a pour but de m'apprendre à configurer les droits d'accès des utilisateurs et les groupes.
